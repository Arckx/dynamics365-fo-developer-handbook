## Role Definitions

### Junior Developer (0-2 years)

| Aspect | Details |
|--------|---------|
| **Focus** | Learn X++, AOT, basic CRUD, simple extensions |
| **Typical Tasks** | Table/field creation, simple CoC, basic forms, unit tests |
| **Supervision** | Close — code reviewed by mid/senior |
| **Key Skills** | X++ syntax, VS debugging, Git, basic SQL |
| **Certifications** | MB-300 (Core), MB-500 (Apps) — in progress |
| **Salary Range (US)** | $65k - $95k |

**Growth Goals:**
- [ ] Complete all 10 OOP exercises
- [ ] Complete all 10 SQL exercises
- [ ] Pass MB-300
- [ ] Build first Data Entity + OData
- [ ] First SysOperation batch job

---

### Mid-Level Developer (2-5 years)

| Aspect | Details |
|--------|---------|
| **Focus** | Independent feature delivery, patterns, performance |
| **Typical Tasks** | Complex CoC, SysOperation, Data Entities, integrations, unit/integration tests |
| **Supervision** | Light — owns features end-to-end |
| **Key Skills** | Advanced X++ (SysDa, RecordInsertList), performance tuning, CI/CD, security/XDS |
| **Certifications** | MB-500 (complete), MB-300 (complete), maybe MB-310/330 |
| **Salary Range (US)** | $95k - $140k |

**Specialization Tracks:**
| Track | Focus |
|-------|-------|
| **Full-Stack F&O** | End-to-end features, forms, batch, entities |
| **Integration** | OData, REST, Logic Apps, Power Automate, dual-write |
| **Performance** | Query tuning, Trace Parser, caching, deadlock resolution |
| **Testing/QA** | SysTest, property-based, RSAT, test automation |

---

### Senior Developer (5-8 years)

| Aspect | Details |
|--------|---------|
| **Focus** | Technical leadership, architecture decisions, mentoring |
| **Typical Tasks** | Design reviews, complex integrations, performance crises, DevOps pipelines, security audits |
| **Supervision** | None — mentors juniors, leads technical decisions |
| **Key Skills** | System design, advanced patterns, Azure, Power Platform, compliance, cost optimization |
| **Certifications** | All MBs + Azure (AZ-204, AZ-400) |
| **Salary Range (US)** | $140k - $180k |

**Leadership Responsibilities:**
- Code review standards
- Technical debt management
- Hiring/onboarding
- Stakeholder communication

---

### Architect (8-12+ years)

| Aspect | Details |
|--------|---------|
| **Focus** | Solution design, strategy, cross-team alignment |
| **Typical Tasks** | Solution blueprints, vendor evaluation, migration planning, governance, cost management |
| **Types:** |
| **Solution Architect** | End-to-end design, non-functional requirements |
| **Technical Architect** | Platform, integration, security, DevOps |
| **Integration Architect** | Enterprise integration patterns, API strategy |
| **Cloud Architect** | Azure, hybrid, disaster recovery, scaling |

**Salary Range (US):** $180k - $250k+

## Certification Roadmap

### Microsoft Certifications (Priority Order)

| Cert | Code | Level | Prep Time | Validity |
|------|------|-------|-----------|----------|
| **Dynamics 365 Core Finance & Operations** | MB-300 | Associate | 4-6 weeks | 1 year |
| **Dynamics 365 Finance & Operations Apps Developer** | MB-500 | Associate | 6-8 weeks | 1 year |
| **Dynamics 365 Finance Functional Consultant** | MB-310 | Associate | 4-6 weeks | 1 year |
| **Dynamics 365 Supply Chain Management** | MB-330 | Associate | 4-6 weeks | 1 year |
| **Developing Solutions for Azure** | AZ-204 | Associate | 4-6 weeks | 1 year |
| **Designing Microsoft Azure Infrastructure** | AZ-305 | Expert | 8-12 weeks | 1 year |
| **DevOps Engineer Expert** | AZ-400 | Expert | 8-12 weeks | 1 year |

### Recommended Sequence

```
Junior:     MB-300 → MB-500
Mid-Level:  MB-310 or MB-330 (module focus) → AZ-204
Senior:     AZ-400 → AZ-305
Architect:  All above + industry certs (PMP, TOGAF, CISSP)
```

## 🔄 Transition Checklists

### Junior → Mid-Level
- [ ] Own features end-to-end (design → deploy)
- [ ] Zero BP warnings in PRs
- [ ] Write integration tests, not just unit
- [ ] Explain "why" not just "how" in code reviews
- [ ] Debug production issues independently
- [ ] Pass MB-500

### Mid-Level → Senior
- [ ] Lead technical design for multi-dev features
- [ ] Mentor 1+ junior developers
- [ ] Define team coding standards
- [ ] Drive performance improvements (>50% gains)
- [ ] Own DevOps pipeline reliability
- [ ] Pass AZ-204 + module cert

### Senior → Architect
- [ ] Design multi-system solutions
- [ ] Define non-functional requirements (scale, security, DR)
- [ ] Evaluate and select vendors/tools
- [ ] Manage technical debt portfolio
- [ ] Communicate technical strategy to business
- [ ] Pass AZ-400 + AZ-305
